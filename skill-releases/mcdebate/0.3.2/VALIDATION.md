# mcdebate 0.3.2 验证记录

日期：2026-10-18。状态：**供 review；尚未在豆包 Work / WorkBuddy 手机端验收，未部署服务端改动**。本版独立保存，0.3.1 归档不修改。

## 本次修正

- 创建或加入房间后，将工具返回的完整 `watch_url` 作为独立一行直接交付，不手写 Markdown 链接，也不重组房间号和 token。无法与原值逐字核对时只交付房间号，不给截断链接。
- 付款人遇到 QUOTED 报价已过期，且当前可见官方 `calculate-price` 时，立即只读重新核价并上报新 QUOTED，然后展示差异、请用户确认是否按新价建单。服务端通用 `await_user` 不等于重新核价需许可；旧报价确认不授权新价建单。
- 服务端的 `checkout_guidance` 同步区分过期报价，提示先核价再确认。观战 URL 仍是现有 64 位 token，未改服务端链接格式。
