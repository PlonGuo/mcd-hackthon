“本地演示餐厅”、参考合计 ¥27.50、四条发言和 87 : 83 均为固定界面测试数据，不能当作真实门店报价、模型评测结果或新一轮豆包／WorkBuddy 联调证据。

预览：在项目根目录运行 `pnpm run preview:watch`，打开 `http://127.0.0.1:8874/watch/preview`。每5秒推进一条发言，约25秒展示预设判决；刷新可重播。
